# DEMONKLIN — Game Concept Portfolio

A responsive, dark-fantasy portfolio site for presenting **DemonKlin**, an original MMORPG concept by independent creator Anup Meshram.

## Current status

- **Project stage:** Concept / pre-production
- **Playable build:** Not represented as available
- **Artwork:** Illustrative concept art; not actual gameplay screenshots
- **Studio:** Independent creator (no studio name claimed)
- **Initial target:** PC-first prototype feasibility

## Publish on GitHub Pages

1. Create a new public repository named `demonklin-game-portfolio` in your GitHub account.
2. Upload all files and folders from this package. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. After GitHub finishes publishing, your site should be available at:
   `https://meanup88.github.io/demonklin-game-portfolio/`

If you use a different GitHub username or repository name, adjust the URL accordingly.

## Files

- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and footer year
- `assets/` — illustrative DemonKlin concept images

## Before submitting to a publisher

Review the wording and ensure the proposal matches the latest GDD. The site intentionally labels the project as a concept and the artwork as illustrative. Do not imply a playable build, production team, secured budget, or completed online world exists unless that changes.
